# Gate high-impact network changes

The home Site will automatically fetch and validate committed network configuration, but changes to DHCP scopes, reservations, core DNS settings, Host addressing, router settings, DNS record deletions, and Technitium versions require a separate operator approval of an exact change plan before application. Updates to the Host address records, cluster records, NS/SOA records, and reverse zone are protected; routine service alias additions and updates may apply automatically after validation. This adds an operator step to prevent an unattended commit from disrupting household connectivity; the deployment tool must reject stale plans. Technitium upgrades proceed one Host at a time, with the secondary checked before the primary is upgraded.
